Trebuche

Every missing curb ramp, found and fixed.

A missing curb ramp turns a curb into a wall for anyone pushing a stroller, using a wheelchair or walker, or pulling a cart. Cities often don't know exactly where ramps are missing. Trebuche checks every corner of a street against public data, shows the evidence, and helps neighbors ask the city to build what's missing.

How it works

  1. Check every corner, crossing by crossing

    A corner usually needs two ramps, one for each street you can cross. Trebuche looks at each crossing, so a corner with just one ramp shows up as a problem instead of passing as "done".

  2. Use more than one source

    City ramp records, volunteer labels from street-level imagery (Project Sidewalk), and OpenStreetMap each miss things. Comparing them corner by corner shows where each one is wrong or out of date.

  3. Ask the right way

    Every corner comes with copy-ready request text and the right city channel. Groups of corners are split to fit the city's forms, with a letter many households can sign.

  4. Track it in the open

    What's been requested, what the city has planned, what's being built this week, and what's done. The data refreshes every day.

How sure is "missing"?

A corner is marked as having no ramp only when at least two independent sources agree. Where sources disagree, the map says so, and the more recent observation wins when the dates make that clear. Anything uncertain is shown as uncertain, so neighbors can go look before filing.

That matters because official maps can be wrong in both directions: on one Seattle street, the city's public map shows ramps that were planned but never built, while volunteer imagery from 2022 misses ramps the city built in 2026. More on that.

Start a street

Trebuche works best where three things exist:

  1. A curb ramp inventory from the city. Many US cities publish one as open data, often with install dates and planned work.
  2. Project Sidewalk or OpenStreetMap coverage. Project Sidewalk runs in dozens of cities, and anyone can add curb details to OpenStreetMap.
  3. Neighbors who'll walk the street. Data gets you most of the way; a quick look settles the uncertain corners.

Today the scripts are set up for one street at a time. Adding another means adjusting a few settings and checking the results. Open an issue on GitHub with the street, the stretch and the city.

About

Trebuche is a neighbor-run project. It isn't affiliated with any city government, and it doesn't file anything for you: every request still goes through the city's own channels.

Everything is open: the code, method and data on GitHub.
