Curb ramps for every corner of Dayton Ave N

Walk Dayton between N 60th and N 85th St with a stroller, a wheelchair, a walker or a cart, and you'll hit a curb with no ramp at almost every block. This is a neighborhood effort to find every missing ramp, show the evidence, and ask the city to build them.

    Our goals

    The end goal is simple: every corner on Dayton Ave N from N 60th to N 85th St has a curb ramp for both crossings. Getting there takes four steps.

    1. Know exactly what's missing

      Not just "this intersection is bad," but which corner, and which of its two crossings has no ramp, backed by public data anyone can check. The data refreshes every day.

    2. Restart work the city already planned

      Some Dayton ramps have been in an SDOT project marked "on hold" since 2022. Asking the city to finish what it started is the quickest win.

    3. Ask together, and ask well

      Complete, evidence-backed requests through the right city channel, split the way SDOT's forms require, plus one letter that many households can sign.

    4. Track it in the open

      Show what's been requested, what the city has planned, what's being built this week, and what's done, so neighbors can follow up instead of starting over.

    Why combine three sources

    No single public source gets Dayton right. Putting them side by side, corner by corner, shows where each one is wrong.

    SDOT's curb ramp inventory

    The city's record of every ramp, with install dates and planned work. It's silent where no ramp was ever recorded, and its public maps draw unbuilt placeholder records at N 79th St as if they were ramps.

    Project Sidewalk

    University of Washington volunteers labeling street-level imagery. It catches missing ramps the city never logged, but its photos are mostly from 2018–2022, so it misses ramps built since, like N 63rd St in August 2026.

    OpenStreetMap

    Community map data, including whether each crossing's curb is raised or lowered. It tells us which crossing at a corner lacks a ramp.

    A corner gets a black X only when at least two sources agree it has no ramp. Where they disagree, the map says so, and the more recent observation wins when dates make that clear.

    About this project

    Started by neighbors on Phinney Ridge. It isn't affiliated with the City of Seattle, and filing through this site isn't a substitute for filing with the city: every request still goes through SDOT's own channels.

    Everything is open: the code and method on GitHub, and the full corner-by-corner data as a spreadsheet (CSV).
